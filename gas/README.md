# 一般內科 PGY 評核後端

此目錄保存 Google Apps Script 原始碼。`action=data` 免密碼讀取儀表板資料；問卷管理名單的登入及儲存仍需要試算表「設定」B4 的管理者密碼。B3 已停用，保留其列位置，勿刪除整列，以免 B4 位移。既有評核資料保持不變。

## 更新既有部署

1. 開啟目前評核試算表的「擴充功能 → Apps Script」。
2. 將原有的後端程式替換成 [PGY評核_Code.gs](PGY評核_Code.gs) 的完整內容後儲存；不要在其他檔案保留重複的函式或常數。不需重新執行 `setup()`。
3. 選擇「部署 → 管理部署作業 → 編輯」，版本選「新版本」，再部署。保持「執行身分：我」及「誰可以存取：所有人」。更新既有部署可沿用目前兩頁的 `CONFIG.GAS_URL`。
4. 用無痕視窗開啟部署網址並加上 `?action=data`，確認收到 `ok: true`，無須 `key` 參數；回應包含正式評核資料，請勿公開貼出。
5. 重新整理 `dashboard.html`，確認直接載入統計；問卷的「管理者登入」仍應要求管理者密碼。

此程式會讓任何取得部署網址的人讀取評核資料（包含評估者姓名及文字回饋）；儀表板畫面仍依原有邏輯隱藏評估者姓名。

## 本機測試

在儲存庫根目錄執行 `node --test tests/gas.test.cjs`。測試以 Apps Script 服務替身驗證免密碼讀取及管理者權限，不會存取正式試算表。實際部署需在 Google Apps Script 完成上述步驟。
